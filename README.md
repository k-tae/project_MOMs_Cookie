## 🧠 프로젝트 소개

**MOM's Cookie**는 바쁜 현대인의 아침을 효율적으로 관리해주는 스마트 비서 시스템입니다.  
하드웨어와 소프트웨어를 통합하여, 사용자의 아침 루틴을 자동화하고 최적화합니다.
